# Contoh Pembagian Tugas Kelompok

| Peran | Tugas | Bukti |
|---|---|---|
| Developer | Membuat atau mengubah fitur KRS, commit, push, dan PR | Branch, commit, Pull Request |
| Tester | Menguji tambah mata kuliah, duplikasi, hapus, dan total SKS | Checklist dan komentar hasil tes |
| Reviewer | Memeriksa kode pada Files changed dan memberi Approve/Request changes | Review PR |
| Operations | Menjalankan aplikasi, memantau Actions, dan mengatur publikasi | Status Actions dan URL aplikasi |

Satu orang boleh merangkap peran jika anggota kelompok terbatas, tetapi proses pengujian dan review tetap harus dilakukan secara nyata.
